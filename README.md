# موقع الرضوان للسيراميك والبورسلين (معاينة)

صفحة رئيسية static، عربي RTL، فاتحة. منشورة على GitHub Pages.

- `index.html` + `img/`: الصفحة الجاهزة.
- `src/store.tpl.html` + `src/products.json`: المصدر. بعد أي تعديل: `python3 src/build.py`.
- الخصومات والعلامات ومبلغ الشحن المجاني في `DEMO` جوه القالب **بيانات تجريبية** لحد الربط بالـ ERP.
- صور المنتجات من كتالوجات الموردين (كليوباترا، مصر سباكة، سلاب) للمعاينة فقط؛ محتاجة إذن المورّد أو صور خاصة قبل الإطلاق.
